Assessment source and limits

This matrix maps the local UAR website to the user-pasted extract from the L5 Diploma in Web Application Development, Unit 2: Interactive Front End Development, qualification specification pages 36–43 (unit A/650/3526). It distinguishes that qualification specification from the earlier UAR Copilot master brief. The extract is the first-hand supplied source used here; it is not an assessor's decision.

The user also supplied a separate Project Requirements list on 27 October 2026 stating that violation of any mandatory requirement results in failure. The matrix below maps those seven requirements directly, separately from the longer qualification-specification criteria. Their wording is not silently combined or replaced.

The extract changes the assessment picture materially: Unit 2 is for a dynamic, interactive front-end application using HTML, CSS and JavaScript, including significant interactive functionality. This repository contains an eight-page informational site with one bounded JavaScript review-planner feature, but no operational UAR product. The planner does not assess actual compatibility or security, and its significance for the whole application has not been confirmed. Do not treat its successful local checks as evidence that the full Unit 2 requirements have been met.

The supplied pages provide pass criteria 1.1–5.4 and several merit criteria, but not all merit wording:

- The extract includes M(i), M(iv), M(v), M(vi), M(vii) and two entries both labelled M(viii).
- It does not show official wording for M(ii) or M(iii). Earlier M(ii)/M(iii) notes in this repository come from the UAR master brief and are not substituted for the missing qualification-specification wording.
- The last distinction guidance is cut off after “few errors in spelling”; no missing ending is inferred.
- Because M(viii) is duplicated (testing documentation and deployment procedure), the matrix labels them “first M(viii) as printed” and “second M(viii) as printed.” The intended numbering needs confirmation from the course provider.

Status meanings: Evidenced means the available record supports the criterion as written; Partial means only part is supported or evidence is incomplete; Not met means the requirement is absent from this project or essential proof is absent; Not assessed means the supplied text is insufficient to map it. These are evidence statuses, not grades.
